### Bugs found & fixed in the POC track
- **Bounded feeds opened at `Date.now()`.** `reload()` always fetched `[now-7d, now]`, so historical data
  showed an empty chart. Fixed with the `Datafeed.getRange?` hook.
- **Newer-bar paging cascade.** v9 keeps the view's offset from the right edge, so appending newer bars
  (Backward) jumped the view to the new end, which fired Backward again until the data ran out. Fixed by
  compensating with `scrollByDistance(n × barSpace)` and declining the re-entrant fire (`holdNewer`).
- **`scrollToTimestamp` puts the bar at the right edge**, not the centre. `jumpTo` centres via
  `scrollToDataIndex(idx + halfScreen)`.
- **Backfill duplicated the oldest bar.** The Forward request used `[before-7d, before]` inclusive; it is now `before-1`.
- **The theme was not a no-op as previously documented.** v9 registers `"dark"`, but it is grid/axis-only
  over a transparent canvas. TickLine now ships complete palettes.

## CRITICAL FINDINGS (don't re-discover)
1. **v9 load semantics:** `Forward` = older (prepend) = backfill; `Backward` = newer (append) = live/forward
   paging, and it fires right after `applyNewData` because the view starts right-pinned.
2. **Backward append keeps the right-edge offset**, so the view jumps to the new end. Compensate with
   `scrollByDistance(+n × barSpace)` (positive = toward older).
3. **Overlay timestamps clamp to the nearest loaded bar** on every redraw, so only draw annotations whose
   bars are loaded (TradeLayer rule).
4. **v9 overlays:** fibonacciLine, horizontalRayLine, horizontalSegment, horizontalStraightLine,
   parallelStraightLine, priceChannelLine, **priceLine**, rayLine, segment, simpleAnnotation, simpleTag,
   straightLine, verticalRayLine, verticalSegment, verticalStraightLine. Custom: `rect`, `tlMarker`,
   `tlPosition`, `tlLevel`.
5. **v9 merges styles, never resets them.** Theme palettes must set the same keys so switching works both ways.
6. **QP Bar `ts` is naive-UTC ISO** (append `"Z"`); QP endpoints take `token:int`; the QP WS emits quote ticks (→ `BarBuilder`).
7. `addData` mutates the data list **synchronously** before its first `await`, so `getDataList()` is current
   right after `params.callback()` / `applyNewData()`.
